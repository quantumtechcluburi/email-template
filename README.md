# email-template
Club template for Emails and Newsletters

## Conventions
- Sent emails go in `past-emails/`, named by the date they were created: `YYYY-MM-DD.html`.
- Subject line (the `<title>`): `QTC@URI · [Sub Subject]`.
- Section dividers: use a 1px cell with `bgcolor` / `background-color`, not `border-top`. Empty `border-top` hairlines often disappear on phones (iOS Mail, Gmail app).
